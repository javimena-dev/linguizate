🚀 Instrucciones para Ejecutar Lingüízate

📋 Paso 1: Abrir Terminal/Consola

Presiona Windows + R, escribe cmd y presiona Enter.

O busca "Símbolo del sistema" en el menú de inicio.

📁 Paso 2: Navegar al Directorio

Escribe el siguiente comando para ir a la carpeta del proyecto:

cd D:\Linguizate\backend

Presiona Enter.

🖥️ Paso 3: Ejecutar Servidor Local

Instala las dependencias y arranca el backend:

npm install
npm start

Presiona Enter y verás el mensaje que confirma el servidor en el puerto 3000.

🌐 Paso 4: Abrir la Aplicación

Una vez que el servidor esté ejecutándose, abre tu navegador web y ve a:

http://localhost:3000

O simplemente haz clic en el botón de abajo:

🎮 Abrir Lingüízate

⚠️ Importante

No cierres la ventana de la terminal mientras uses la aplicación. El servidor debe seguir ejecutándose.

Para detener el servidor, presiona Ctrl + C en la terminal.

🎯 ¿Por qué necesito esto?

El backend sirve la interfaz y conserva usuarios, preguntas y partidas en SQLite. Por eso la aplicación debe abrirse desde el servidor y no directamente como un archivo.

¿Necesitas ayuda? Revisa la consola del navegador (F12) para ver mensajes de error detallados.
